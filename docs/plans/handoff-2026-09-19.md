## 8 — Traps, added to this session

Everything in [handoff-2026-09-12.md](handoff-2026-09-12.md) §6 still holds. New:

- **A pinned `plan evaluate` run never fetches**, so it cannot populate the
  event-live cache it needs. Run it once *without* `--snapshot` to fetch, then
  again pinned for the citable figures — and discard the first run's numbers,
  which are projected from the current bootstrap and are leaky.
- **`plan evaluate`'s table truncates model names** at normal terminal width, to
  `compo…` — three of the six rows are indistinguishable. Set `COLUMNS=220`. The
  criterion is a comparison between two of those rows, so reading them off a
  truncated table is how you would get the decision backwards.

  as `0.330` against `0.329`; the actual delta is 0.000517 and the rounding
  intervals happen not to overlap, but nothing on screen tells you that.

  FU-71. Full variant names are refused at the flag.

  test asserting an exact Start% under the `component` alias has to give its
